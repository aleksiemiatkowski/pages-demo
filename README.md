# Pages Lab

Prosta statyczna strona do testowania publikacji na GitHub Pages.

## Uruchomienie lokalne

Otworz `index.html` w przegladarce albo uruchom dowolny prosty serwer HTTP, np.:

```bash
python -m http.server 8000
```

Nastepnie wejdz na `http://localhost:8000`.

## Struktura

- `index.html` - strona startowa
- `gallery.html` - galeria powierzchni i typografii
- `playground.html` - interaktywny test JavaScript
- `styles.css` - wspolne style
- `app.js` - motyw i filtrowanie galerii
- `playground.js` - generator kolorow
